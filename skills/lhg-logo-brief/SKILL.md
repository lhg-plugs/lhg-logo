# lhg-logo-brief：品牌简介→设计简报

> 目标：把一句"想要个 logo"变成设计师能直接开工的简报。
> 核心纪律：**简报没确认，不许画第一笔**——返工 90% 来自简报不清。

## 1. 何时使用

- 用户说"帮我设计个 logo" → 先读本 skill，做简报
- 简报信息不全 → 按第 3 节五问补齐，最多问两轮
- 改 logo/升级 logo → 先做"资产审计"（第 5 节），再写简报

## 2. 输入与输出

**输入**：用户的一句话品牌介绍（想到哪说到哪都行）。
**输出**：`brief.md`（设计简报）+ `brand.json`（结构化品牌数据，供审计脚本用）。

## 2.5 简报坏味道（写完对照闻一闻）

- [ ] 通篇没有出现具体数字（用户年龄？场景频次？一个都没有 → 太空）
- [ ] 调性词全是褒义词（"专业/高端/可信" → 没有张力，等于没说）
- [ ] 避让清单写的是"暂无"（→ 不可能没有竞品，是没去找）
- [ ] 应用场景写"全场景"（→ 等于没写，主场景必须唯一）
- [ ] 品牌名是用户随口起的英文名+中文名对不上（→ 先定名再定 logo，顺序不能反）

闻到一条 → 打回重写对应节。坏简报进流程，等于把返工分期付款——利息很高。

`brand.json` 格式（本插件各环节通用）：

```json
{
  "brand": "品牌名",
  "tagline": "一句话定位",
  "audience": "目标受众",
  "adjectives": ["调性词1", "调性词2", "调性词3"],
  "avoid": ["竞品/风格避让清单"],
  "palette": {"主色": "#1A56DB", "辅色": "#F5F7FA"},
  "backgrounds": {"浅底": "#FFFFFF", "深底": "#111827"},
  "contrast_pairs": [["主色", "浅底"], ["主色", "深底"]],
  "exports": [
    {"size": 16, "purpose": "favicon"},
    {"size": 180, "purpose": "社交头像"},
    {"size": 1024, "purpose": "印刷/官网"}
  ],
  "variants": {"dark": true, "mono": false},
  "clearspace": "以标志高度 x 为单位，四周留白 ≥ x/4",
  "min_size_px": 24,
  "originality_check": "待做：商标近似检索"
}
```

## 3. 分步方法论：简报五问

### 一问：你是谁（定位）
- 品牌名、中英文、做什么业务、一句话定位。
- 挖一层：**如果只能让用户记住一个词，是哪个词？**（这个词是 logo 概念的种子）

### 二问：给谁看（受众）
- 核心用户是谁？年龄/场景/审美偏好。
- 反例警示：给 Z 世代做潮牌和给 B 端企业做 SaaS，logo 语言完全不同——受众错了，后面全错。

### 三问：什么气质（调性）
- 要 3–5 个形容词，且**必须成对出现张力**（如"专业但不严肃"" playful 但可信"）。
- 单维度形容词（"高端大气"）等于没说——追问"高端到什么程度？跟谁比高端？"

### 四问：不能像谁（避让）
- 列出 3 个同行/竞品 logo，明确"不要像它们"。
- 这是原创性的第一道防线：**不知道避让对象，就无法证明原创**。

### 五问：用在哪（场景）
- 首发场景 + 最高频场景：APP 图标？门头？社交媒体头像？印刷包装？
- 场景决定技术约束：APP 图标要求 16px 可辨认，门头要求远距离可读——见 lhg-logo-geometry。

## 3.5 简报访谈话术（别把五问念成审问）

五问是提纲，不是考卷。参考话术：

| 问 | 生硬版 ❌ | 聊天版 ✅ |
|---|---|---|
| 定位 | "请描述你的品牌定位" | "如果只能让用户记住你们的一个词，你希望是哪个？" |
| 受众 | "目标受众画像是什么" | "你希望谁看到这个 logo 会心动？描述一个具体的人" |
| 调性 | "请给出 3–5 个调性词" | "如果你的品牌是一个人，他穿什么衣服、说什么话？" |
| 避让 | "请列出竞品" | "有没有哪个同行的 logo 是你绝对不想像的？发我看看" |
| 场景 | "应用场景有哪些" | "logo 做好第一件事用在哪？门头、APP 还是公众号头像？" |

**访谈纪律**：用户每答一问，复述一遍确认（"我理解你是…对吗"）；两轮问不完就先出 v0.1 版简报让用户改——**让用户改稿比让用户答卷轻松**。

## 4. 简报确认清单
`brief.md` 写完后，用户逐项确认：

- [ ] 定位一句话准确（用户原话，不是你的发挥）
- [ ] 3–5 个调性词用户认（不认就换，不许"差不多"）
- [ ] 避让清单 ≥3 个（没有就一起找）
- [ ] 主场景明确（决定最小尺寸与导出清单）
- [ ] 色彩倾向：有偏好就记，没有就写"由设计师提案 3 套"

## 4.5 brand.json 字段填写指南（给机器看的简报）

`brief.md` 给人看，`brand.json` 给审计脚本看。字段填写要求：

| 字段 | 填什么 | 不许 |
|---|---|---|
| `brand` / `tagline` | 品牌名 + 一句话定位（用户原话） | 写你的发挥版 |
| `adjectives` | 3–5 个调性词数组 | 只写 1 个，或写"高端大气" |
| `avoid` | ≥3 个避让对象（品牌名+一句话特征） | 空数组 |
| `palette` | 主色+辅色，hex 大写 6 位 | 只写颜色名不写 hex |
| `backgrounds` | 至少"浅底/深底"两个 | 只有一个背景 |
| `contrast_pairs` | 要计算的[前景, 背景]组合 | 凭感觉不写 |
| `exports` | 7 类场景的尺寸清单（见 lhg-logo-export 第 3 节） | 写"到时候再说" |
| `variants` | `{"dark": true/false, "mono": true/false}` | 不填（默认当 false 审） |
| `clearspace` / `min_size_px` | 简报阶段可写"待定"，几何规范阶段落定 | 一直待定到交付 |
| `originality_check` | "待做：商标近似检索"也算填 | 空字符串（等于没表态） |

**校验**：`brand.json` 写完跑一遍 `logo_audit.py --check-brand-only`（如支持）或直接进下一环节——审计脚本会在 SVG 审计时一并校验 brand.json 完整性。

## 5. 改 logo 专项：资产审计

老品牌升级 logo，先审计再简报：

1. **沿用资产**：老 logo 里用户/市场已认知的元素是什么？（颜色？图形？字形？）——能留则留，品牌资产别白扔
2. **问题清单**：老 logo 具体哪里不行？（16px 糊成一团？深色底没法用？跟竞品撞脸？）——每个问题对应新 logo 的一条硬指标
3. **过渡方案**：是否需要"演进式"而非"革命式"改版？（老用户认知的连续性）

## 6. 反模式

- ❌ 简报只有一句话就开画——返工预定
- ❌ 调性词用"高端大气上档次"——等于没说
- ❌ 不问避让对象——撞脸了才知道
- ❌ 用户说"随便，你定"就真随便——至少给出 3 个方向让用户选，选了才是确认
- ❌ 简报写完不存 brand.json——后面审计脚本没输入，全流程断裂

## 7. 自检与反馈

每次做完简报自检：

1. `brief.md` 用户确认了吗？（没确认=没做完）
2. `brand.json` 字段齐了吗？（palette/backgrounds/exports/variants 四项是审计脚本的输入）
3. 避让清单 ≥3 个吗？

标准冒烟：跑 `scripts/audit/logo_audit.py` 扫 `fixtures/bad`，确认尺寸覆盖与对比度规则命中（见仓库根 `smoke_test.py`）。

反馈渠道：以 `[QC] <一句话问题>` 为标题提交到 https://github.com/lhg-plugs/lhg-logo/issues，正文写清"品牌简介 → 实际简报 → 期望简报"。
