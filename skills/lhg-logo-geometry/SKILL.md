# lhg-logo-geometry：几何规范

> 目标：让 logo 成为"资产"而非"一张图"——任何人按规范都能复现它。
> 核心纪律：**没有几何规范的 logo 不许进导出环节**。

## 1. 何时使用

- 概念已选定（`concepts.md` 中标了 1 个）→ 读本 skill 做规范
- 收到一个"jpg 版 logo"要转成规范资产 → 按第 3 节重建
- 审计发现 SVG 不规范 → 按第 4 节清单逐项修

## 2. 输入与输出

**输入**：选定的概念（concepts.md 中的 1 个）+ `brand.json`。
**输出**：`spec.md`（几何规范文档）+ `logo.svg`（规范源文件）+ 更新 `brand.json`（clearspace/min_size/variants 落定）。

## 3. 分步方法论：规范五件套

### 件一：网格构建（grid）
- 选网格：8×8 或 12×12（简单图形用 8，复杂用 12）。
- 所有关键锚点落在网格交点或中点上；圆的圆心、半径用整数网格单位。
- `spec.md` 里画出网格示意图（ASCII 或 SVG 注释均可），并写清："本标志所有曲线控制点均为网格整数倍"。

### 件二：安全区（clearspace）
- 定义：以标志高度为 x，四周留白 ≥ x/4（或以标志中某个元素为单位，如字母"O"的宽度）。
- 安全区内不许放文字、图形、版式边缘——这是 logo 的"社交距离"。
- 写入 `brand.json` 的 `clearspace` 字段。

### 件三：最小尺寸（min-size）
- 测出 logo 在多少 px 以下会糊成一团（通常 16–24px 是坎）。
- 规定：`min_size_px`（如 24）——小于此尺寸必须用简化版（去细节）或纯文字版。
- **APP 图标场景必测 16px**：favicon 是 logo 的"地狱模式"。

### 件四：单色版本（mono）
- 纯黑版 + 纯白（反白）版各一：单色下图形还成立吗？
- 单色是 logo 的"体检"：靠颜色撑起来的 logo，单色一测就露馅。
- 传真/雕刻/单色印刷场景只能用单色版——没有单色版 = 资产不完整。

### 件五：深浅底适配（theme）
- 浅底版、深底版分别定稿：深底不是"把浅底反个色"就行，要单独调（细节在深底上会糊）。
- `brand.json` 的 `variants.dark=true` 且深底版单独有一个 SVG 文件（如 `logo-dark.svg`）。

## 3.5 网格选择决策树

```
图形复杂度如何？
├─ 简单（≤3 个基本形）→ 8×8 网格
│   └─ 例：字母变形、单图形
├─ 中等（4–8 个元素）→ 12×12 网格
│   └─ 例：图形+文字组合
└─ 复杂（徽章/多层）→ 16×16 网格
    └─ 例：emblem 徽章式

图形是圆的？
├─ 是 → 网格+同心圆双系统（圆心落网格点，半径取整数格）
└─ 否 → 纯网格系统
```

**网格不是装饰**：规范文档里必须能回答"这个圆为什么是这个半径"——答案是"3 个网格"，不是"看着顺眼"。

## 4. SVG 源文件规范（logo_audit.py 逐项检查）

| 要求 | 说明 | 审计规则 |
|---|---|---|
| 必须有 `viewBox` | 如 `viewBox="0 0 240 240"`，缩放不失真 | SVG-VIEWBOX-001（blocker） |
| 建议带 `width`/`height` | 默认渲染尺寸 | 无则 warning（配合 viewBox 可接受） |
| 文字必须转曲 | `<text>` 元素在交付文件中不许出现（转成 `<path>`），否则换台机器就变样 | SVG-TEXT-001（warning，提醒转曲） |
| 无空元素 | 空 `path`（`d=""`）、零尺寸图形 | SVG-EMPTY-001（blocker） |
| 带 `<title>` | 无障碍：读屏软件能读出"XX 品牌 logo" | SVG-TITLE-001（nit） |
| 路径精简 | 锚点数控制在合理范围（审计不硬性卡，人工看） | — |

**文字转曲提醒**：设计稿阶段可以用 `<text>`（方便改字），但**交付文件必须转曲**——这是 SVG-TEXT-001 存在的原因。

### 常见 SVG 坑位对照表

| 坑 | 症状 | 解法 |
|---|---|---|
| 无 viewBox，只有 width/height | 放大缩小失真，响应式失效 | 补 `viewBox="0 0 <w> <h>"` |
| `<text>` 未转曲 | 换台机器字体变了，logo 走样 | 交付前转曲，设计稿保留文字版备份 |
| 小数位过多 | `d` 属性里 6 位小数，文件臃肿 | 保留 2–3 位小数即可 |
| 隐藏图层/垃圾元素 | 设计工具导出带一堆隐藏元素 | 导出前清理，或跑审计 SVG-EMPTY-001 |
| 渐变没转纯色 fallback | 印刷/单色场景渐变糊掉 | 重要版本提供纯色 fallback |

## 5. 规范文档模板（spec.md）

```markdown
# Logo 几何规范 — <品牌名>

## 1. 网格
8×8 网格，标志外框占 6×6 居中，四周各留 1 格呼吸位。

## 2. 关键尺寸（单位：网格）
- 外圆直径：6
- 内环间距：0.5
- 缺口角度：60°

## 3. 安全区
以标志高度 x 为单位，四周留白 ≥ x/4。

## 4. 最小尺寸
24px；小于 24px 用简化版 logo-simple.svg。

## 5. 色彩
- 主色 #1A56DB（浅底用）/ #7CA3F5（深底用，单独调过）
- 单色版：logo-mono.svg（纯黑）、logo-mono-rev.svg（纯白）

## 6. 版本清单
| 文件 | 用途 |
|---|---|
| logo.svg | 主版本（浅底） |
| logo-dark.svg | 深底版 |
| logo-mono.svg / logo-mono-rev.svg | 单色版 |
| logo-simple.svg | 小尺寸简化版（<24px） |
```

## 6. 反模式

- ❌ 概念直接导出 PNG 交付——没有 SVG 源文件 = 没有资产
- ❌ 深底版 = 浅底版反色——细节会糊，必须单独调
- ❌ 安全区"大概留点白就行"——不写进规范，等于没有
- ❌ 交付文件里留 `<text>`——"在我机器上是好的"是经典翻车
- ❌ 最小尺寸不测——favicon 上糊成一团才发现

## 7. 自检与反馈

每次做完规范自检：

1. `logo_audit.py` 跑一遍，blocker 清零？
2. 16px 下看一眼：还认得出来吗？
3. 深浅底、单色版四个文件都在吗？

标准冒烟：坏 fixture 的 SVG（无 viewBox、含 `<text>`、空 path）埋点必须命中。

反馈渠道：以 `[QC] <一句话问题>` 为标题提交到 https://github.com/lhg-plugs/lhg-logo/issues。
