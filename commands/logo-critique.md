# /lhg-logo:logo-critique —— 概念评审

用户输入在 `$ARGUMENTS` 中：`[concepts.md 路径]`。缺省 `concepts.md`。

可分派给 `originality-reviewer` agent 独立评审（与设计师隔离，避免自己评自己）。

## 流程

### 1. 原创性审查
- 拿 3 个概念逐个与 `brand.json` 的 `avoid` 避让清单比对：第一眼像吗？核心图形语言撞车吗？
- 审查结论三档：**通过** / **需调整**（指出像在哪、怎么改）/ **否决**（撞脸明显，回炉）。
- 审查只基于简报里的避让清单 + 公开常识，**不构成商标检索**。

### 2. 商标风险提示（必须说，不许吞）
- 明确告知用户：本评审不能替代专业商标近似检索；正式商用前建议：
  1. 各国商标数据库近似查询（如中国商标网、USPTO TESS）；
  2. 反向图片搜索，看有无高度近似的现有标识；
  3. 高风险行业（餐饮/服装/美妆）建议咨询商标代理人。
- 把这段话写进交付的 `CHECKLIST.md`，并更新 `brand.json` 的 `originality_check` 字段（如"已提示用户做商标近似检索，2026-10-11"）。

### 3. 三项生存测试
- **16px 测试**：概念在 16px 下还成立吗？不成立 → 要求简化版或换方向。
- **单色测试**：纯黑/纯白下图形还成立吗？靠颜色撑起来的概念打回。
- **深底测试**：深底上需要大改吗？需要大改说明概念对背景依赖过强。

### 4. 交付
- 评审报告（每概念：原创性结论 + 三项测试 + 风险提示确认）。有一票否决 → 回炉，不许进几何规范。

## 硬规则
- 承诺"这个商标肯定能注册" → 不许，这是红线。
- 自己设计自己评审 → 不许走过场；正式项目建议换 agent/换人评。
- 风险提示没写进交付物 → 等于没说，不许。
